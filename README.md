# Веб-приложение (дашборд) для инференса ML-моделей и анализа данных

Данный репозиторий содержит расчетно-графическую работу по дисциплине **«Машинное обучение и большие данные»**.

- 🎯 **Тема РГР:** Разработка Web-приложения (дашборда) для инференса (вывода) моделей ML и анализа данных  

---

## 📊 Описание датасета и задачи
В рамках работы был выбран набор данных для задачи классификации.

* **Предметная область:** Предсказания срабатывания пожарной сигнализации
* **Целевой признак:** `Fire Alarm`
* **Основные этапы предобработки (EDA):** Обработка пропущенных значений, удаление дубликатов, нормализация данных.

---

## 🤖 Используемые модели машинного обучения
Для инференса в веб-приложении выбраны 6 лучших моделей на основе метрики **F1-score для классификации**, полученных в ходе лабораторных работ:

1. **ML1 (Классическая модель):** Линейная регрессия
2. **ML2 (Ансамбль / Бустинг):** Gradient Boosting
3. **ML3 (Продвинутый бустинг):** CatBoostRegressor
4. **ML4 (Ансамбль / Бэггинг):** Бэггинг
5. **ML5 (Ансамбль / Стэкинг):** Stacking
6. **ML6 (Нейросеть):** Tensorflow

*Все модели были сериализованы на жесткий диск с помощью встроенных инструментов фреймворков (TensorFlow, CatBoost) и стандартного модуля `pickle` для моделей Sklearn.*

---

## 🖥️ Структура веб-приложения (Дашборда)
Приложение реализовано на фреймворке **Streamlit** и имеет многостраничную структуру:
* **Страница 1. Разработчик:** Информация об авторе работы, учебной группе и тема исследования.
* **Страница 2. Описание датасета:** Подробный разбор предметной области, описание признаков и фич-инжиниринга.
* **Страница 3. Визуализация данных:** Интерактивный разведочный анализ (EDA) с использованием библиотек Matplotlib и Seaborn.
* **Страница 4. Инференс (Предсказание):** Интерфейс для генерации прогнозов. Реализован как ручной ввод параметров через интерактивные виджеты (с валидацией и указанием единиц измерения), так и пакетная загрузка данных через `*.csv` файл.
